Health sync

Send your steps, Move, weight and food from Apple Health to the Progress page every day

← Progress

How it works

An Apple Shortcut on your iPhone reads today’s numbers from the Health app and sends them here. An automation runs it for you each night when you plug your phone in. Your iPhone keeps Health data locked while the phone is locked, so plugging in (when you’ve usually just used it) works better than a fixed time.

It sends steps, Move (active energy) and today’s weigh-in. If Lose It writes your food log into Apple Health, it can send your food kilojoules, protein, carbs and fat too.

Install it with one tap

The first time it runs, your iPhone asks a few things. To let it send everything:

  • When it asks to read Health data, tap Turn On All, then Allow. Missed one? Run it again from the Shortcuts app, or check Settings → Health → Data Access & Devices → Shortcuts.
  • If it says it can’t send a large amount of data, turn on Settings → Apps → Shortcuts → Advanced → Allow Sharing Large Amounts of Data. Move (from an Apple Watch) is lots of small readings.
  • When it asks to connect to this site, tap Always Allow.
  • If this site’s address is a number (like 192.168…), the sync only works on your home Wi-Fi. That suits the automation in step 3, which runs when you plug in at night.
Make or update the install file (admins, on a Mac)

iPhones only open shortcut files that a Mac signed into iCloud has approved. You do this once, and again if this site’s address changes.

  1. On the Mac, open this page and click Download the shortcut file. It goes to Downloads as Health sync (unsigned).shortcut.
  2. Open Terminal (in Applications → Utilities), paste this and press Return:
    cd ~/Downloads && shortcuts sign --mode anyone --input "Health sync (unsigned).shortcut" --output "Health sync.shortcut"

Or: describe it (iOS 27 and later)

Newer iPhones can build a shortcut from a description. Make your sync key in step 1 first, so it’s filled in below.

  1. Tap Copy under the description below.
  2. Open the Shortcuts app and tap +. Where it asks what you want your shortcut to do, paste the description and send it.
  3. Check what it made: it should read Steps, Active Energy, Weight and the food amounts from Health, then Get Contents of URL with your sync address. Save it as Health sync.
  4. Tap the shortcut once to run it. Allow it to read Health data and to connect when asked. The Last sync line in step 1 shows what arrived (tap Check again). If a number is missing, ask the Shortcuts app to fix it (for example “also send my weight”), or use the step-by-step way below.

Your iPhone sends the description to Apple Intelligence to build the shortcut, and it includes your sync key. The key can only add numbers here: it can’t read anything or log in. You can make a new key at any time.

Step by step instead (about 10 minutes)

On your iPhone, open the Shortcuts app. On iOS 27 and later, tapping + asks what you want the shortcut to do: look for the option to build it yourself, or type each action’s name below into the search and tap it.

  1. Tap + (top right). Tap the name at the top and call it Health sync.
  2. Steps. Add these actions (search for each one in the bar at the bottom):
    • Find Health Samples: tap the type and choose Steps. Tap Add Filter if there isn’t one, and set it to Start Date is today.
    • Calculate Statistics: Sum of Health Samples.
    • Set Variable: name it Steps, set to Statistics.
  3. Move. The same three actions again, with type Active Energy and the variable named Move.
  4. Weight. Find Health Samples with type Weight, Start Date is today, Sort by Start Date, Order Latest First, Limit on, 1. Then Set Variable named Weight, set to Health Samples.
  5. (Optional, if Lose It writes to Apple Health) Food. Repeat step 2 four times, with types Dietary Energy, Protein, Carbohydrates and Total Fat, and variables named Food, Protein, Carbs and Fat.
  6. The date. Add Date (it says Current Date), then Format Date: tap Date Format, choose Custom, and type yyyy-MM-dd. Then Set Variable named Day, set to Formatted Date.
  7. Send it. Add Get Contents of URL. Paste your sync address (from step 1) as the URL, then tap the arrow to show more:
    • Method: POST.
    • Headers: Add new header. Key Authorization, value Bearer, a space, then your sync key.
    • Request Body: JSON. Add these fields (tap Add new field, pick the kind, type the key, then pick the variable):
      dateTextDay
      stepsNumberSteps
      active_energyNumberMove
      weightTextWeight
      energy_unitTextkJ (type it; use kcal if your Health app shows Calories)
      food_energyNumberFood (optional)
      proteinNumberProtein (optional)
      carbsNumberCarbs (optional)
      fatNumberFat (optional)
  8. (Optional) Add Get Dictionary Value: key message from Contents of URL, then Show Notification with the Dictionary Value, so you see “Synced steps, Move…”.
  9. Tap Done, then tap the shortcut once to run it. Allow it to read Health data and to connect to this site when asked. The Last sync line below shows what arrived (tap Check again).

3. Make it run by itself

  1. In Shortcuts, tap Automation at the bottom, then + (or New Automation).
  2. Choose Charger, tick Is Connected, and choose Run Immediately. Tap Next.
  3. Choose your Health sync shortcut.

Each run replaces that day’s numbers with the latest, so running it more than once a day is fine. You can also add a Time of Day automation (say 9 pm) as a backup, or tap the shortcut whenever you like.

Lose It

Lose It doesn’t let other apps read your food log directly: it has no public connection for apps like this one. There are two ways to get it here:

  1. Automatic: if your Lose It app can connect to Apple Health (look in Lose It’s settings under apps and devices), turn on writing food and nutrients to Health. Then the optional food steps above send your daily kilojoules, protein, carbs and fat here.
  2. By hand: export your data from Lose It and upload the file on the My files page. The Progress page reads it.
